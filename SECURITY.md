# Security and data handling

## Reporting a vulnerability

Please report security concerns privately through the email listed on the [maintainer's GitHub profile](https://github.com/Parth-Oza). Include reproduction steps and expected impact.

## Data policy

Only synthetic measurements and trajectories belong in this repository. Do not submit employer data, facility maps, calibration files, device identifiers, credentials, or private operational logs.

## Numerical safety

This repository is an educational reference, not a safety-certified localization component. A production integration must add system-specific validation, time synchronization, outlier handling, watchdogs, monitoring, and safety review.
