# Architecture and mathematical model

## State

The filter tracks a planar constant-velocity state:

```text
x = [position_x, position_y, velocity_x, velocity_y]
```

The transition matrix advances position using the current velocity. An optional planar acceleration control input advances position and velocity through the same elapsed-time control matrix. Process noise is generated by mapping independent planar acceleration variance through that matrix.

## Measurement models

- Position updates observe the first two state components.
- Velocity updates observe the final two state components.
- Each public update accepts an isotropic variance and builds a 2×2 noise matrix.

Measurements can arrive at different rates. The caller controls when to predict and which sensor update to apply, keeping timing semantics explicit.

## ROS 2 replay boundary

`bag_replay` uses the pure-Python `rosbags` reader so the example can process rosbag2 SQLite and MCAP storage without requiring a sourced ROS installation.

1. Connections are validated against configured topics and exact standard message types.
2. Bag timestamps determine each prediction interval at nanosecond resolution.
3. The most recent planar IMU acceleration is held between messages and applied as a control input.
4. Each odometry message supplies position and velocity corrections.
5. The corrected state, odometry reference, and residual are recorded for CSV export.
6. Aggregate replay-consistency metrics are written as JSON.

The transport layer is deliberately outside `ConstantVelocityEKF`. The mathematical core has no ROS imports and remains directly testable.

### Assumptions and failure behavior

- The IMU x/y acceleration is gravity-compensated and already expressed in the odometry frame.
- The bag reader provides messages in timestamp order; regressions are rejected.
- Missing topics, mismatched message types, invalid variance, deserialization failures, and non-finite sensor values fail explicitly.
- Odometry is the exported reference signal, not independent ground truth. Residual metrics measure replay consistency only.
- Frame transforms, orientation compensation, clock synchronization, bias estimation, and delayed-measurement smoothing remain outside this example.

## Numerical stability

- Kalman gain is computed with `numpy.linalg.solve`, avoiding an explicit inverse.
- Covariance uses the Joseph form after each correction.
- A symmetry guard removes small floating-point asymmetry.
- Invalid time steps and non-positive variances fail immediately.

## Extension path

The current model is intentionally small. Natural extensions include:

- Independent noise covariance per measurement axis.
- Heading, yaw-rate, or acceleration state.
- Nonlinear observation models and angle normalization.
- Innovation gating and outlier rejection.
- Timestamped sensor queues and delayed measurements.
- A live ROS 2 node that translates messages without coupling middleware to the filter core.

Each extension should include seeded experiments and tests that establish expected behavior.
